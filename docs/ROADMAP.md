# 路线图（ROADMAP）

## 版本策略

- 语义化版本，唯一来源是 `src/engine.py` 里的 `VERSION`（构建/打包/安装脚本都从这里读）；
- 每次发布：改 `VERSION` → 更新 `CHANGELOG.md` → `git tag vX.Y.Z` → CI 出 Release 附件；
- 只改引擎（大多数情况）：**重新发布 exe 即可**，ppam 不用动（见 `docs/PACKAGING.md` §6）。

## 已知限制（不是 bug）

- 构建 ppam 必须有桌面版 PowerPoint；
- 需要 PowerPoint 正在运行才能响应按钮（引擎附着当前实例）；
- 旋转后的图片无法做原像素裁取（像素映射非线性），会直接拒绝；
- 图片被删除后重新插入同一张图，标定不继承（Tag 丢在旧 shape 上）；
- **链接式图片**（"链接到文件"插入，未嵌入原图）不算图片资产：引擎读不到内嵌原图，
  标定会提示"无法唯一确定标定线属于哪张图片"，裁取也无法进行。改用"插入图片"默认方式即可。
